## 八、搜索渠道优先级

1. **WebSearch 通用搜索**（默认，混合关键词+平台维度）
2. **站点限定**：关键词 + `site:bilibili.com` / `site:dxy.cn` / `site:zhihu.com` / `site:mp.weixin.qq.com`
3. **定向来源名**：上表平台/UP 主/公众号名 + 主题词
4. **搜狗微信**（weixin.sogou.com）：微信专属索引，命中率高但偶发反爬
